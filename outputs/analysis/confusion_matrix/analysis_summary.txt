======================================================================

Majority class: nv (67.08%).
Majority/minority count ratio: 66.0:1.

Accuracy and weighted F1 are dominated by the majority class (nv). Macro F1 and balanced accuracy average all seven classes equally, so they better reflect rare-class errors. This analysis does not change the model.

Observed error structure (descriptive)
----------------------------------------------------------------------
nv is both the largest class and the class with the highest recall. Melanoma (mel) and benign keratinocytic lesions (bkl) are frequently confused with nv, which is consistent with overlapping dermoscopic appearance. Accuracy is therefore easier to achieve than balanced rare-class performance.

These observations are not a reason to retrain, retune thresholds, or re-select checkpoints. The test split remains a frozen holdout.
